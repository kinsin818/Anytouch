# 军令：S5-g 服务端激活双校验
**日期**：2026-09-26
**项目根目录**：D:\Anytouch
**主目标**：实现激活码+设备MD5双校验，接入Vultr服务器，一个激活码最多绑定2台设备。

## 要求
1.  **服务器端（Vultr 45.32.63.177）**：
    -  新增一个轻量HTTP接口，路径`/api/activate`，和现有AI众议院服务部署在同一台服务器，不额外加钱
    -  接口入参：激活码字符串、设备MD5字符串
    -  接口逻辑：
        -  激活码在白名单里→记录该激活码绑定的设备MD5列表
        -  如果列表<2台，把这个MD5加进去，返回激活成功
        -  如果列表已经满2台且当前MD5不在列表里，返回拒绝（已绑满）
        -  如果MD5已经在列表里，直接返回激活成功
    -  激活码白名单先预置100个生成好的码，存在服务器SQLite数据库里
2.  **APP端改造**：
    -  激活的时候不再只做本地校验，改成把激活码+本机硬件MD5一起POST到咱们服务器接口
    -  服务器返回成功才写入本地激活状态，返回失败就弹对应提示（码无效/已绑满2台设备）
    -  本地保留校验逻辑作为离线兜底：没网的时候也能用之前激活过的状态
3.  **UI文案全英文**，错误提示明确：
    -  "Activation code invalid"
    -  "This code has already been activated on 2 devices, maximum reached"
    -  "Activation successful"
4.  改完重打APK，推v1.0.6 Release，匿名验证可下载
