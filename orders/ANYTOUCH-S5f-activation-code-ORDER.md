# 军令：S5-f 激活码功能
**日期**：2026-09-25
**项目根目录**：D:\Anytouch
**主目标**：APP加激活码校验，支持Gumroad付费解锁。

## 要求
1.  首页加"Activate"按钮，点开弹出激活码输入框
2.  激活码规则：格式为 `ANY-XXXX-XXXX-XXXX`，本地校验：
    -  总长度19位，前3位固定ANY，中间用-分隔
    -  后三段共12位字符，每4位一组，校验和按简单算法（前两位字符ASCII和取模26转字母）
3.  激活状态存在本机SharedPreferences，激活成功后解锁三个高级功能：重复循环、任务保存列表、手动补步骤；未激活时这三个功能入口置灰，提示"Upgrade to Pro"
4.  激活码不联网校验，本地算对就放行，不做服务器验证
5.  界面文案全英文，无中文
6.  改完重打APK，推v1.0.5 Release，匿名验证可下载
