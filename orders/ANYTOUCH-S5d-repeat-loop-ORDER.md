# 军令：S5-d 重复执行功能
**日期**：2026-09-25
**项目根目录**：D:\Anytouch
**主目标**：给APP加重复执行的两个小功能，满足养号/重复操作用户需求。

## 要求
1.  执行界面加两个输入框：
    -  Repetitions：默认1次，用户可以填1-100轮
    -  Interval：每轮间隔多少秒，默认5秒，范围1-60秒
2.  加随机偏移：实际等待时长 = 设定间隔 ± 随机1秒（比如设5秒，实际每轮在4-6秒之间随机），避免行为太机械被平台检测
3.  执行逻辑：一轮任务跑完→等间隔时长（带随机偏移）→自动开下一轮，直到跑完设定的轮数
3.  急停球全程可点，点了立刻停所有后续轮次
4.  高危确认弹窗只在第一轮跑之前弹一次，后面重复轮不再重复弹（不打扰用户）
5.  安全门禁/执行器/编译链路零改动，只是在外面包一层循环逻辑
6.  改完重打APK，推v1.0.3 Release，匿名验证可下载
