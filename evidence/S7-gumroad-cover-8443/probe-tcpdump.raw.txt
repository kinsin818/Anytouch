## 机内防火墙排除项（与抓包同机同时段取）

```
$ iptables -S | head
-P INPUT ACCEPT
-P FORWARD ACCEPT
-P OUTPUT ACCEPT
...
-A INPUT -p tcp -m tcp --dport 9000 -j DROP
```
`nft list ruleset` 的 INPUT 链：`policy accept` + 仅 `tcp dport 9000 ... drop`，ufw-* 链全空。
⇒ **8443 上的超时不是机内 netfilter 丢的**（netfilter 在网卡抓包点之后，而抓包点就没见到包）。

## 追加（同批，口径精确化，不覆盖上方原文）

上方"与 ss-before.txt 逐行一致"一句机械复核后收紧口径：脚本取 `LISTEN` 开头行比对，
`ss-before.txt` 全量监听表 **7 行**与 `ss-after.txt` **7 行逐行一致**；`ss-before.txt` 另有第 8 行
`LISTEN 0      5            0.0.0.0:8443      0.0.0.0:*`，那是同文件末尾 `=== listening 8443 ===`
一段 grep 摘录对同一条 8443 行的**重复**，不构成新增监听。443 在两度读数里都不存在任何监听（v4/v6 皆无）。
