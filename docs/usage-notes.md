# 使用须知与已知设备限制（用户向）

> 本文件随 S4 上线文案军令引用；口径=老板裁决 T3-R2（2026-09-22）。

## 已知限制

### MIUI（小米魔改 ROM）：系统设置首页无法被自动滚动
- 现象：在 MIUI 设置首页直接录制/执行"滚动"步骤时，系统容器拒绝无障碍滚动指令，任务会诚实报错停止（不会假成功）。
- 规避：**先在首页手动向上滑一下，再开始录制或执行**；或进入任意二级页面后录制。
- 说明：这是该 ROM 对无障碍接口的定制行为，非本 App 缺陷；在原生安卓（Pixel 等）实测正常。较新的 HyperOS（红米 K80/Android 16 实测）无此限制，本条仅约束 MIUI。

### 小米系（MIUI + HyperOS）：系统设置搜索框拒绝程序化输入
- 现象：对设置页搜索框执行"输入文本"步骤时，系统控件拒绝全部无障碍输入通道，任务诚实报错停止。
- 规避：在小米系设备上请**手动点入搜索框并键入**，或逐级点击进入目标页后录制。
- 说明：原生安卓与 AVD 矩阵实测输入正常（双通道：SET_TEXT 及剪贴板粘贴兜底），属厂商 ROM 定制，非本 App 缺陷。

## 装机与首启引导话术（S4 / 军令 R3-2 引用件）

> 口径来源：本文件每条"话术"都对应一条**设备实证**（右侧括注证据），无证据的支持性建议一律不写成承诺。
> 已上线界面文案为英文（产品只出海），本节中文是**口径源**，S4 文案军令按此翻译，不得加戏。

### G1 首启三件事（无障碍 → 悬浮球 → 选目标 App）
- 话术：**"① 在『设置 → 无障碍 → 已下载的服务』里打开 Anytouch（这一步系统不允许我们用任何方式代劳）；② 允许显示悬浮球——开录和紧急停止都在它上面；③ 在录制页填上要自动化的应用包名（当前版本只对『设置』做过完整验收，别的 App 属尝鲜）。"**
- 依据：无障碍绑定与悬浮球是产品执行链的硬前提（第 10 颗雷把"球挂不上"定成拒绝执行，而非默默跑）。
- 诚实边界：**引导页不得出现"一键授权/自动开启"**——AOSP 起无障碍开关只能用户亲手点，写了就是假承诺。

### G2 小米 / 红米（MIUI）：别用"强行停止"，也别让清理加速工具杀它
- 现象：MIUI 上应用被**强行停止**（设置里的"强行停止"、一键清理/加速类工具）后，系统会**直接删除**本 App 的无障碍开关条目，不是"停了但还勾着"。
- 话术：**"小米/红米机型请别对 Anytouch 用『强行停止』，也别让清理加速类工具动它——这些机型会把无障碍权限整条删掉，需要重新到设置里打开。"**
- 依据：第 13 颗雷（K40/MIUI V816 实测 `force-stop` 清空绑定条目；AOSP 与 AVD 三档均只停不删）。
- 诚实边界：**"覆盖安装/系统更新后权限是否保留"未实测**，故话术不承诺"更新不受影响"，只写实测过的那一条。
- 备注：测试通道同批已禁用裸 `force-stop`（自家回归脚本也遵守这条，避免假红）。

### G3 红米（HyperOS）等：用 adb 脚本配权限要开两个开关（只关乎开发者/极客路径）
- 现象：HyperOS 上通过 adb 写入无障碍绑定，系统**不报错但静默回滚**——写完还是没绑上。开启『开发者选项 → USB 调试（安全设置）』并把目标包加入调试白名单后才持久。
- 话术（放 FAQ / 高级设置页，不放首启引导，避免吓到普通用户）：**"如果你在通过 adb 写无障碍绑定做调试：小米/红米机型需要先开『USB 调试（安全设置）』并把本 App 加入调试白名单，否则系统会静默还原你的写入。普通用户直接在设置里手动打开即可，不涉及这个开关。"**
- 依据：第 14 颗雷（K80/HyperOS/Android 16 实测）。
- 诚实边界：**"手动在设置里打开会被回滚"未观测到**，故话术明确限定 adb 路径，不外推。

### G4 遇到"莫名拒做/输入没落字"，先重启手机再判
- 现象：同一台设备、同一条任务，曾在同一轮内从"输入正常"变成"输入被拒"，重启后自愈；三类常见解释（自动填充服务、系统版本、目标页内容）逐一被证伪。
- 话术：**"如果某一步突然一直失败、而昨天还能跑：请先重启手机再试一次（不是重装 App）。重启后仍复现，请把『执行报告』那一屏截图发给我们——里面写明了卡住的原因。"**
- 依据：AVD MarvisPhone 一次性 SET_TEXT/PASTE 双拒态 + 重启自愈实录（`evidence/S2/t3-avd-matrix.md`）。
- 诚实边界：该案例取证在**模拟器**上，真机同形未复验；因此措辞是"先重启再判"的排查次序，不写成"重启能解决 ROM 问题"的承诺。

### G5 未覆盖机型的诚实声明（Samsung / Moto 等）
- 话术：**"目前我们在原生安卓模拟器三档镜像（API 31/34/35，含 MarvisPhone 基准档）与小米系两台真机上做过验收；Samsung / Moto One 等机型尚未实测。你在这些机型上遇到任何一步失败，是我们最需要的一条反馈。"**
- 依据：老板裁决 T3-R4 以"既有真机 + AVD 三档矩阵"替代采购真机，Samsung/Moto 缺口按裁决**写入上线风险段**，不作"全机型可用"表述。
- 红线：成功率口径只写"已实测机型"的数字（模拟器 MarvisPhone 上军令原判据 **8 步链 ×10 轮 10/10 全绿、逐轮录 8 编 8 放 8**；另有 3 步链 10/10），**不得**写成机型无关的"≥90% 成功率"。

## 录制建议
- 输入密码/敏感文本时，可在录制过程中手动键入——本 App 不接管输入法，也不读取剪贴板历史。
- 高危步骤（命中密码/支付/账号类词表）执行前必弹二次确认，**无人点击=默认拒绝**，属设计行为。
- 录制过程请一次做完再停止：中途切走、下拉通知栏这类"跟任务无关的操作"会被如实录成步骤，多录一步就多跑一步；删改步骤的编辑页尚未上线，只能重录。
