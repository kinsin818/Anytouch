# 使用须知与已知设备限制（用户向）

> 本文件随 S4 上线文案军令引用；口径=老板裁决 T3-R2（2026-09-22）。

## 已知限制

### MIUI（小米魔改 ROM）：系统设置首页无法被自动滚动
- 现象：在 MIUI 设置首页直接录制/执行"滚动"步骤时，系统容器拒绝无障碍滚动指令，任务会诚实报错停止（不会假成功）。
- 规避：**先在首页手动向上滑一下，再开始录制或执行**；或进入任意二级页面后录制。
- 说明：这是该 ROM 对无障碍接口的定制行为，非本 App 缺陷；在原生安卓（Pixel 等）实测正常。较新的 HyperOS（红米 K80/Android 16 实测）无此限制，本条仅约束 MIUI。

### 小米系（MIUI + HyperOS）：系统设置搜索框拒绝程序化输入
- 现象：对设置页搜索框执行"输入文本"步骤时，系统控件拒绝全部无障碍输入通道，任务诚实报错停止。
- 规避：在小米系设备上请**手动点入搜索框并键入**，或逐级点击进入目标页后录制。
- 说明：原生安卓与 AVD 矩阵实测输入正常（双通道：SET_TEXT 及剪贴板粘贴兜底），属厂商 ROM 定制，非本 App 缺陷。

## 录制建议
- 输入密码/敏感文本时，可在录制过程中手动键入——本 App 不接管输入法，也不读取剪贴板历史。
- 高危步骤（命中密码/支付/账号类词表）执行前必弹二次确认，**无人点击=默认拒绝**，属设计行为。
